# Week 0 — Pre-Check

Validate prerequisites and confirm the toolchain works before Week 1.

## Prerequisites to verify

1. **Command line** — navigate, pipe, permissions, environment variables
2. **Git & GitHub** — clone, branch, commit, push, PR, resolve a merge conflict
3. **Python basics** — variables, control flow, functions, collections, reading a stack trace
4. **HTTP** — you type a URL, something comes back (hand-wave level)

## Deliverable

Open a PR to the `reference/fieldbook-starter` repo that adds a function and a passing test. This confirms Git, Python, and the toolchain all work before Day 1.

## Checklist

- [ ] Python 3.13 installed via `uv`
- [ ] Can run `uv run pytest`, `uv run ruff check .`, `uv run mypy .`
- [ ] Git configured (name, email, SSH/HTTPS auth)
- [ ] Opened a PR with a function + passing test
- [ ] All prereqs self-assessed as comfortable
